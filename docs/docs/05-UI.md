# 5. UI (User Interface)

## What is UI?

UI (User Interface) is everything that the user can see and interact with on the screen.

Examples:

- Buttons
- Text
- Images
- Lists
- Text Fields
- Cards

---

# Android

Android provides two ways to build UI.

## XML (Traditional)

UI is created using XML files.

Example:

```xml
<TextView
    android:text="Hello Android"/>
```

---

## Jetpack Compose (Modern)

UI is created using Kotlin code.

Example

```kotlin
@Composable
fun Greeting() {
    Text("Hello Android")
}
```

Jetpack Compose is now the recommended way to build Android UIs.

---

# React Native

React Native builds UI using JavaScript/TypeScript with JSX.

Example

```tsx
function HomeScreen() {
  return (
    <Text>Hello React Native</Text>
  );
}
```

Everything is written inside components.

---

# Android vs React Native

| Android | React Native |
|----------|--------------|
| XML | JSX |
| Jetpack Compose | React Components |
| @Composable | Functional Component |
| Modifier | style |
| setContent {} | return () |


---

# Component

In React Native, everything is a Component.

Example

```tsx
function LoginScreen() {
    return (
        <Text>Login</Text>
    )
}
```

You can reuse components anywhere.

This is very similar to reusable Composable functions in Android.

---

# Styling

Android

Uses

- Modifier
- Material Theme

Example

```kotlin
Text(
    text = "Hello",
    modifier = Modifier.padding(16.dp)
)
```

---

React Native

Uses

- StyleSheet

Example

```tsx
<Text style={styles.title}>
    Hello
</Text>
```

```
const styles = StyleSheet.create({
    title:{
        fontSize:20
    }
})
```

# Best Practices

✅ Keep UI simple.

✅ Create reusable components.

✅ Avoid duplicate code.

✅ Separate UI from business logic.

✅ Keep screens clean.

# Interview Questions

### What is JSX?

JSX is a syntax that allows developers to write UI using JavaScript/TypeScript.

---

### What is a Component?

A Component is a reusable piece of UI.

---

### What is the difference between XML and JSX?

XML is a markup language.

JSX is JavaScript with UI syntax.

---

### What is similar to Jetpack Compose?

React Components.

---

# Summary

Android developers create modern UIs using Jetpack Compose.

React Native developers create UIs using React Components written in JSX.

Both approaches are declarative, reusable, and encourage building small UI components.
