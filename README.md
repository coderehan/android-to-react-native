# 🚀 React Native for Android Developers

> A complete roadmap for Android developers who want to learn React Native.

This repository is designed specifically for Android developers who already know **Kotlin, Jetpack Compose, MVVM, Clean Architecture, Retrofit, Room, Hilt**, etc., and want to transition into **React Native** without reading hundreds of pages of documentation.

Instead of learning everything from scratch, every concept is explained by comparing it with Android development.

# 📱 Android vs React Native

| Android | React Native |
|----------|--------------|
| Kotlin | TypeScript |
| XML | JSX |
| Jetpack Compose | React Native Components |
| Activity | Screen |
| Fragment | Screen |
| RecyclerView | FlatList |
| Navigation Component | React Navigation |
| ViewModel | Zustand |
| LiveData | Zustand |
| Retrofit | Axios |
| Room | WatermelonDB |
| SharedPreferences | MMKV |
| Coil | FastImage |
| Hilt | React Context API |
| WorkManager | Background Fetch |
| CameraX | Vision Camera |
| Google Maps | react-native-maps |
| Firebase | React Native Firebase |
